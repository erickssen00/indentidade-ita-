# Style Guide / Guia de Estilo: Itaú

Este repositório contém a documentação das diretrizes visuais (Tipografia e Paleta de Cores) baseadas no arquivo de especificação do Itaú[cite: 1].

---

## 🎨 Paleta de Cores

A paleta de cores está organizada por hierarquia e função, com variações de tonalidade (tom abaixo/escuro, tom base e tom acima/claro)[cite: 1].

### 1. Cores Primárias (Laranja Itaú)[cite: 1]
* **Primário -1:** `#CC4E00`[cite: 1]
* **Primário (Base):** `#FF6200`[cite: 1]
* **Primário +1:** `#FF8133`[cite: 1]

### 2. Cores Secundárias (Azul)[cite: 1]
* **Secundário -1:** `#1866BE`[cite: 1]
* **Secundário (Base):** `#267FE3`[cite: 1]
* **Secundário +1:** `#539AE9`[cite: 1]

### 3. Cores Escuras (Dark / Neutras Escuras)[cite: 1]
* **Dark -1:** `#0B0A0A`[cite: 1]
* **Dark (Base):** `#262323`[cite: 1]
* **Dark +1:** `#403B3B`[cite: 1]

### 4. Cores Claras (Light / Neutras Claras)[cite: 1]
* **Light -1:** `#D3DDE4`[cite: 1]
* **Light (Base):** `#F2F5F7`[cite: 1]
* **Light +1:** `#FFFFFF`[cite: 1]

### 5. Sucesso (Success / Feedback Positivo)[cite: 1]
* **Success -1:** `#2FC63E`[cite: 1]
* **Success (Base):** `#52D65F`[cite: 1]
* **Success +1:** `#7BE085`[cite: 1]

### 6. Perigo / Alerta (Danger / Feedback Negativo)[cite: 1]
* **Danger -1:** `#FF2705`[cite: 1]
* **Danger (Base):** `#D11C00`[cite: 1]
* **Danger +1:** `#9E1500`[cite: 1]
